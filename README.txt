Sarkar Getaways website (HTML + CSS + JavaScript only)

Files:
- index.html: page structure
- css/style.css: all styling, including replacement utility classes and original component styles
- js/script.js: sliders, carousels, package selection, and inquiry form interaction

No Tailwind CSS is used. The site still loads Google Fonts and Font Awesome from their CDNs and uses remote Unsplash images, so an internet connection is needed for those external assets. The inquiry form currently shows a confirmation message in the browser; it does not send the enquiry to a server.

Keep the folder structure unchanged and open index.html in a browser.
